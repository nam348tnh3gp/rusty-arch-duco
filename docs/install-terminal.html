📖 Installation Guide

Follow these steps to install Rusty Arch Duco on your system. This guide will help you create a bootable USB drive and start mining Duino-Coin.

This installation will create a dedicated mining environment. Make sure to backup any important data before proceeding.

Step 1: Download the Image

Visit the GitHub Actions page to get the latest build:

https://github.com/nam348tnh3gp/rusty-arch-duco/actions

Go to GitHub Actions →

Download the latest successful build artifact (arch-duco.img.xz).

Step 2: Extract the Image

After downloading, extract the compressed image file:

xz -d arch-duco.img.xz

This will create arch-duco.img which is ready to be flashed.

Step 3: Flash to USB Drive

WARNING: This will erase all data on the target drive! Double-check the device path before proceeding.

Flash the image to your USB drive (replace /dev/sdX with your actual USB device):

sudo dd if=arch-duco.img of=/dev/sdX bs=4M status=progress sync

Alternative method using balenaEtcher: If you prefer a GUI tool, download balenaEtcher from balena.io/etcher and flash the image easily.

Step 4: Boot from USB

  1. Insert the USB drive into your computer
  2. Restart your computer
  3. Enter boot menu by pressing:
    • F12 (Dell, Lenovo)
    • ESC (HP, ASUS)
    • F10/F11 (Acer, Samsung)
    • DEL (Desktop PCs)
  4. Select your USB drive from the boot menu
  5. The system will boot into Rusty Arch Duco
If your computer doesn't boot from USB, you may need to disable Secure Boot in BIOS/UEFI settings.

Step 5: Login and Mine!

Once booted, use these default credentials:

Username: miner
Password: miner

After logging in, start mining with:

./mine.sh

Or configure your miner manually by editing config.ini.

Troubleshooting

  • USB not recognized? Try a different USB port (preferably USB 2.0)
  • Boot fails? Check if Secure Boot is disabled in BIOS
  • No mining hashrate? Verify your internet connection and pool settings
  • Need help? Open an issue on GitHub
✅ After successful installation, your system will be optimized for mining Duino-Coin with maximum efficiency!
