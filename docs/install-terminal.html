📖 Installation Guide

Step 1: Download the Image

Visit the GitHub Actions page to get the latest build:

https://github.com/nam348tnh3gp/rusty-arch-duco/actions

Step 2: Extract the Image

xz -d arch-duco.img.xz

Step 3: Flash to USB Drive

⚠️ WARNING: This will erase all data on the target drive!

sudo dd if=arch-duco.img of=/dev/sdX bs=4M status=progress sync

Step 4: Boot from USB

  • Insert the USB drive
  • Restart your computer
  • Enter boot menu (F12, ESC, or DEL)
  • Select USB drive to boot

Step 5: Login and Mine!

Default credentials:

  • Username: miner
